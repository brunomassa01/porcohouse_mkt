# Contexto da Porco House TV

Material importado do texto enviado por Bruno em 20/10/2026.

- [Arquivo-mestre em Markdown](arquivo-mestre.md): leitura e histórico de alterações no GitHub.
- [Documento Word](Porco_House_TV_Arquivo_Mestre_de_Instrucoes.docx): versão para compartilhar com a equipe.
- [Texto original](texto-original.txt): cópia integral do material recebido, que contém código Python.
- [Gerador do Word](gerar_documento.py): código recebido com o caminho de saída adaptado para esta pasta.

Para gerar novamente o Word, execute `python contexto/gerar_documento.py` na raiz do repositório, com `python-docx` instalado. O gerador usa o conteúdo do script, não lê o Markdown; ao atualizar o contexto, mantenha as versões sincronizadas.

O material registra contexto, exemplos e decisões reportadas; não comprova disponibilidade de talentos, escala atual, calendário ou fatos atuais sobre o Palmeiras. Novas orientações de Bruno prevalecem sobre este registro. Os ativos citados, como planilhas, logos e vinhetas, não vieram anexados.
